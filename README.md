# dear-near

Tools for a new analysis of NEAR Shoemaker magnetometer observations at Eros.

## setup

All downloaded data and generated products are hardcoded to
`/Users/danywaller/Projects/near`:

- `/Users/danywaller/Projects/near/data` contains PDS MAG data and SPICE kernels
- `/Users/danywaller/Projects/near/output` contains figures and PSD arrays

## data sources

- [NEAR MAG PDS4 bundle](https://sbnarchive.psi.edu/pds4/near/near_mag/)
- [NEAR SPICE archive](https://naif.jpl.nasa.gov/pub/naif/pds/data/near-a-spice-6-v1.0/nearsp_1000/)
